ENERGI

Energi i Home Assistant: el, solceller, batteri og omkostninger

Forfatter: Tomasz Furdal · HA Expert

Home Assistant kan bruges til mere end at vise det aktuelle elforbrug.

Med de rette data kan systemet samle import og eksport, solcelleproduktion, batteriets energistrømme, omkostninger og forbruget fra udvalgte apparater.

Det giver grundlag for både statistik og automatik, som flytter forbrug til mere fordelagtige tidspunkter.

GRUNDLAG

Effekt og energi er ikke det samme

Effekt, normalt målt i watt eller kilowatt, beskriver det aktuelle tempo for forbrug eller produktion. Energi, typisk målt i kilowatttimer, beskriver mængden over tid.

En enhed, der bruger 2000 W i en time, forbruger cirka 2 kWh. Forskellen er vigtig ved valg af entiteter og Energy-statistik.

DATA

Hvad kan Home Assistant vise?

Afhængigt af datakilderne kan Home Assistant vise:

  • energi importeret fra og eksporteret til elnettet;
  • produktion fra solceller;
  • batteriets energistrømme;
  • forbrug fra enkelte apparater;
  • energiomkostninger;
  • forbrug af gas og vand.
ELNET

Import og eksport af energi

I et hjem med solceller er to retninger vigtige: import fra elnettet og eksport tilbage til det.

Måling af begge gør det muligt at vurdere egetforbrug og overskud. Data kan komme fra en måler, energiselskabets integration, inverteren eller ekstra måleudstyr.

SOLCELLER

Solcelleproduktion

Produktionsdata kan komme fra inverteren, en energimåler eller en passende integration.

Når produktion kombineres med import og eksport, bliver energistrømmen tydeligere end ved kun at se den samlede produktion. Det viser egetforbrug og tidspunkter med overskud.

BATTERI

Batterilager

Hvis installationen har et batteri, kan Home Assistant medtage energi, der oplades til og aflades fra lageret, når de nødvendige data findes.

Dashboardet fastlægger ikke batteriets strategi. Styring afhænger af den konkrete inverter, batteriet og integrationen.

PRISER

Energiomkostninger

Prisen på 1 kWh kan afhænge af tarif, tidspunkt, elmarked, nettariffer og afregningsregler. Prisstrukturen varierer mellem lande og aftaler.

Home Assistant kan bruge omkostningsdata eller prisentiteter. Ved dynamiske priser kan man analysere, hvornår bestemte apparater er billigst at bruge.

APPARATER

Forbrug fra enkelte apparater

Kompatible målere, intelligente stikkontakter, målemoduler og integrationer kan levere data for enkelte apparater.

Det hjælper med at finde store forbrugere og vælge, hvilke der kan omfattes af energiautomatik. Korrekte målehierarkier forebygger dobbelttælling.

DATAKILDER

Hvor kommer dataene fra?

Kilder kan være intelligente målere, målerporte, solcelleinvertere, batterier, tavlemålere, stikkontakter med måling og integrationer fra energiselskaber.

Entiteterne skal have korrekte enheder og egenskaber, blandt andet passende device_class og state_class. Ét produkt passer ikke til alle installationer.

AUTOMATIK

Energy-dashboardet er kun begyndelsen

Grafer forklarer forbruget, men større muligheder opstår, når automatik bruger dataene.

Home Assistant kan træffe beslutninger ud fra elpris, solcelleproduktion, eksporteret overskud, batteriniveau, temperatur, behov og tidspunkt.

STYRING

Hvad kan automatiseres?

Afhængigt af installationen kan energidata styre varmt vand, elpatron, opladning af elbil, batteri, opvarmning og andre forbrugere, hvis drift sikkert kan flyttes.

Ikke alle enheder bør styres efter pris alene. Automatikken skal også tage hensyn til komfort, sikkerhed og udstyrets krav.

OVERSKUD

Solceller og overskudsenergi

Når produktionen overstiger forbruget, kan overskuddet eksporteres. I nogle installationer kan lokal brug til varmt vand, batteri eller en anden fleksibel forbruger være mere fordelagtig.

Resultatet afhænger af købs- og salgspriser, virkningsgrad og afregning. Strategien skal bygge på data fra den konkrete installation.

OPVARMNING

Elektricitet og opvarmning

Energipriser og tilgængelig energi kan indgå i varmestyringen. Med flere varmekilder kan omkostningen ved at producere den nødvendige varme sammenlignes.

Det er ikke nok at sammenligne 1 kWh el med 1 kWh brændsel. Virkningsgrad, varmepumpens COP, afgifter, temperatur og systemets begrænsninger skal medregnes.

BESPARELSER

Kan Home Assistant sænke regningen?

Home Assistant reducerer ikke forbruget af sig selv. Det kan levere information og automatik, som bruger energi, når den er billigere eller kommer fra egen produktion.

Den faktiske besparelse afhænger af installationen, tarifferne, styringsmulighederne og husets brug. En bestemt procent kan ikke loves ansvarligt.

FØRSTE SKRIDT

Hvor skal man begynde?

Undersøg først, om du har:

  • import og eksport fra måleren;
  • solcelleproduktion;
  • opladning og afladning af batteriet;
  • aktuelle energipriser;
  • måling af store forbrugere;
  • enheder, som kan styres sikkert.

Først derefter bør dashboard og automatik planlægges.

HJÆLP

Har du brug for hjælp med energi i Home Assistant?

Hvis du har solceller, energimåler, batteri, dynamiske priser eller forbrugere, som skal tilpasses pris og produktion, kan jeg vurdere installationen og integrationsmulighederne.

Jeg kan også hjælpe med målinger, Energy-dashboardet og automatik baseret på priser, solcelleproduktion og reelt forbrug.
