KNX & INTEGRATIONS

KNX and Home Assistant: what you can integrate and what you need

Author: Tomasz Furdal · HA Expert

KNX can control lighting, blinds, heating and other building functions on its own. Home Assistant does not need to replace it. It can work as an additional layer that brings KNX data into one interface and connects the installation with other systems in the home.

If KNX already works correctly, the key question is what is worth exposing to Home Assistant and what should remain in KNX.

TWO SYSTEMS

KNX and Home Assistant are two different systems

KNX is a building automation system where essential functions can continue to work independently of Home Assistant. Wall switches, lighting, blinds and heating do not need to depend on one central server.

Home Assistant can sit above KNX as an integration layer. This makes it possible to combine KNX data and controls with devices and services that are not part of the KNX installation itself.

BENEFITS

Why connect Home Assistant to an existing KNX installation?

The main benefit is not replacing KNX. It is connecting KNX with the rest of the home.

Dashboard

Home Assistant can bring lighting, blinds, temperatures, heating, sensors and other KNX functions into one interface together with devices outside KNX. The guide to the Home Assistant dashboard explains how to plan one.

Automations across systems

KNX data can be combined with presence, weather, energy, alarms, surveillance, multimedia and other Home Assistant integrations.

Energy and heating

Home Assistant can combine KNX data with electricity prices, solar production, battery storage and other data sources when they are available in the system. See the guide to energy in Home Assistant.

Multimedia and surveillance

KNX does not need to handle everything. Home Assistant can connect building automation with a television, AV receiver, audio system, cameras or surveillance. See the guides to multimedia and Hikvision cameras.

REQUIREMENTS

What do you need to integrate KNX with Home Assistant?

Before integration, check these four things:

KNX/IP interface or KNX/IP router

Home Assistant needs access to the KNX bus through an IP device. This can be a KNX/IP interface or a KNX/IP router. Whether the existing device is sufficient depends on the communication method and the current installation. There is no reason to replace working hardware simply because Home Assistant is being added.

ETS project and group addresses

The ETS project makes integration much easier because it shows which functions and group addresses are already available. A function that works from a wall switch does not automatically mean that every useful status address is available to Home Assistant. If something is missing on the KNX side, a change in ETS may be required.

KNX Secure

If the installation uses KNX Secure, the information required for the secure connection also has to be available, usually a keyring file exported from ETS. Verify the exact requirements against the current Home Assistant and KNX documentation before implementation.

Home Assistant

Home Assistant can run on Green, Raspberry Pi, a mini PC or other supported hardware. The host itself does not change the KNX integration principle as long as Home Assistant has reliable network access to KNX/IP.

SCOPE

What can usually be exposed to Home Assistant?

Depending on the ETS project and available group addresses, Home Assistant can usually work with functions such as:

  • lighting and dimming;
  • RGBW;
  • blinds and shutters;
  • temperatures;
  • heating and HVAC states;
  • motion and presence sensors;
  • scenes;
  • central functions;
  • other values and states exposed by KNX.

The actual scope always depends on what exists in the KNX project.

LIMITS

What should Home Assistant not replace?

If essential building functions already work correctly without Home Assistant, it usually makes sense to keep them that way.

Lighting, blinds and heating should not stop working simply because Home Assistant is offline, updating or has a network problem.

Home Assistant is most useful as an additional interface, data layer and automation platform that connects several systems.

INSTALLER

When do you need a KNX installer or ETS?

If the required group addresses and functions already exist, much of the work can be done on the Home Assistant side.

A KNX installer or someone working in ETS may be needed when:

  • group addresses are missing;
  • there is no status feedback for a device;
  • logic running directly in KNX needs to be changed;
  • KNX devices need to be added or reprogrammed;
  • Secure configuration requires changes in the project.
PROBLEMS

Common integration problems

A problem does not automatically mean that Home Assistant is at fault. The cause can be a lack of an available KNX/IP tunnel, a missing status address, an incorrect DPT, Secure configuration, or the difference between routing and tunnelling.

Before changing a working KNX installation, first establish what is already available in ETS and how KNX/IP currently communicates. It also makes sense to have a current Home Assistant backup.

HELP

Do you want to connect an existing KNX installation to Home Assistant?

If you already have a working KNX installation and want to connect it to Home Assistant, I can review the ETS project, available group addresses and KNX/IP setup and determine what can be safely exposed to Home Assistant. I can also prepare a dashboard and automations that connect KNX with other systems in the home.
