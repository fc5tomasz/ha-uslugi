Satel Integra and Home Assistant: what you can integrate and what to check first

Author: Tomasz Furdal · HA Expert

You have a Satel Integra alarm and Home Assistant. You want the two to know about each other: lights that react to the alarm state, and a phone that shows which partition is armed.

This guide helps you decide whether your installation is ready for that. It shows what Home Assistant can actually see, what it can control and what it will not handle. It also covers what to check before anyone changes the settings in the control panel.

This is not a step by step tutorial. The integration touches your alarm system, so the details always depend on the specific control panel, module and configuration.

COMPATIBILITY

Can a Satel Integra alarm work with Home Assistant?

Yes, if a few conditions are met. Home Assistant has a built-in Satel Integra integration. It runs locally on your home network, without a manufacturer cloud.

The integration uses the open SATEL integration protocol and talks to the control panel through the ETHM-1 Plus Ethernet module. The module pushes state changes as they happen, so Home Assistant does not have to keep asking the panel for its status.

This applies to control panels from the INTEGRA and INTEGRA Plus series. PERFECTA and VERSA panels can work with the ETHM-1 Plus module, for example through the mobile app, but SATEL only describes the integration function for INTEGRA panels.

In short: an INTEGRA or INTEGRA Plus panel with an ETHM-1 Plus module is the starting point. Without it, the built-in Home Assistant integration will not work.

REQUIREMENTS

What hardware and configuration the integration needs

The connection needs preparation on both sides: in the alarm system and in Home Assistant. Four things matter most. On top of that, Home Assistant must be able to reach the module on the local network, ideally at a fixed IP address.

An INTEGRA or INTEGRA Plus panel

SATEL states that the integration function requires control panel firmware 1.06 or newer. You can check the version in DLOADX or from a keypad.

The ETHM-1 Plus module

The Home Assistant documentation only lists the ETHM-1 Plus module with firmware 2.00 or newer. The older ETHM-1 module is not listed as supported. If the panel has no Ethernet module, one has to be installed and configured first.

The integration function enabled

The integration option must be enabled in the module settings, with a port set, 7094 by default. Integration encryption can be enabled as well, with a key. This is done in DLOADX or in service mode on a keypad.

Partition, zone and output numbers

Home Assistant does not import the whole panel structure. Each partition, zone and output is added separately, using its number from the panel configuration. That is why you need a current description of the system or access to the DLOADX project.

WHAT YOU SEE

What you will see in Home Assistant

The integration only creates entities for the items you add to it. Each of them can then be part of a dashboard, a notification or an automation.

Partitions

Each partition you add gets its own alarm panel. It shows whether the partition is disarmed, fully or partially armed, in exit or entry delay, and whether there is an alarm.

Zones (detectors and sensors)

Each zone you add appears as a binary sensor: violated or not. This is how motion detectors, door and window contacts or flood detectors wired to the panel show up in Home Assistant.

Outputs

The state of selected panel outputs, such as a siren or a control output, can also be shown in Home Assistant as a sensor.

Temperature

If a zone supports temperature measurement, the integration can show it as a separate sensor. This only applies to zones that have that measurement.

CONTROL

What Home Assistant can control

Home Assistant can send three kinds of commands to the panel:

  • arm a partition fully or in a partial mode, chosen in the partition settings in Home Assistant from the panel's arming modes;
  • disarm a partition, and clear the alarm if one was active;
  • switch controllable outputs on and off, if you add them to the integration.

Every one of these commands needs a user code from the panel. Without a code, Home Assistant will not send the command.

What the code can do depends on its rights in the alarm system. If the code has no access to a partition, it cannot arm that partition from Home Assistant either.

The panel always has the final say. It can refuse to arm, for example when a zone is violated. Home Assistant does not bypass that logic.

LIMITS

What Home Assistant does not show or support

The SATEL protocol provides more information than the Home Assistant integration currently uses. Before you connect the two, it helps to know what you will not see in Home Assistant:

  • zone and module tamper states;
  • bypassing selected zones before arming, and forced arming;
  • system troubles, such as battery, power supply or communication problems;
  • the panel event log;
  • macros from the SATEL mobile app.

There is also one important difference in how alarms are shown. A fire alarm and an intrusion alarm in a partition appear in Home Assistant as the same state: triggered. If that difference matters for your notifications, it has to be taken into account when the logic is designed.

Home Assistant does not replace the alarm control panel. The panel still watches the detectors, triggers the alarm and talks to the monitoring station, if it is connected to one. Home Assistant receives status information and can send the commands it is allowed to send.

USE CASES

What you gain by connecting the alarm to the rest of the house

The main benefit is not seeing the alarm in one more app. It is a house that reacts to the alarm state and to the detectors that are already installed.

  • when the whole house is armed, Home Assistant can switch off forgotten lights or selected devices;
  • a detector triggered at night can turn on dimmed lighting along the route instead of waking the whole house;
  • the alarm's motion detectors and door contacts can support lighting, heating and presence automations;
  • a notification can say which partition changed state, not just that something happened.

How to build rules like these so they behave predictably is covered in the guides on Home Assistant automations and presence automations. If you have cameras, see how Hikvision cameras can be part of a smart alarm system. An example dashboard that combines the alarm with cameras is shown in the Cameras and alarm project.

BEFORE YOU START

What to check before you start the integration

Before anyone changes the panel settings, it is worth collecting a few facts:

  • the control panel model and its firmware version;
  • whether there is an ETHM-1 Plus module, and which firmware it runs;
  • who has access to DLOADX, the panel project and the service code;
  • whether the system is connected to a monitoring station or covered by a service agreement;
  • whether the module is already used by another system for integration;
  • which partitions, zones and outputs should appear in Home Assistant;
  • whether you need control or whether reading the states is enough;
  • which network the module is on and whether Home Assistant can reach it.

If the module already serves another integration system, check how the two should work together before connecting Home Assistant. Do not assume that both will run side by side.

INSTALLER

When you need a SATEL installer

Some of the work needs service access to the control panel. The Home Assistant documentation itself recommends asking your installer to make the changes if you do not have access to DLOADX or the project file. Most often this involves:

  • installing or replacing the ETHM-1 Plus module;
  • updating the module or panel firmware;
  • enabling the integration function, changing the port and setting the encryption key;
  • creating a separate user code with suitable rights;
  • setting up the arming modes that Home Assistant will use.

If the system is monitored or covered by a service agreement, agree any panel changes with the company that looks after it. The Home Assistant integration should not interfere with what already protects the house.

SECURITY

Security and access

A connection to the alarm system is one more way into the control panel. It is worth setting it up sensibly from the start.

A separate code for Home Assistant

The code Home Assistant uses should only have the rights it actually needs. Do not use the service code or a code with full administrator rights.

Integration encryption

The ETHM-1 Plus module can encrypt integration traffic with a key set in the control panel. The Home Assistant integration supports both encrypted and unencrypted connections.

Local network only

The integration port should not be reachable from the internet. The module can also limit connections to selected IP addresses or subnets. Remote access to Home Assistant is better handled separately, for example as described in the guide on Home Assistant remote access.

Disable the integration when you stop using it

If you no longer need the integration, the Home Assistant documentation recommends disabling the integration function in the ETHM-1 Plus module. This reduces the risk of unauthorised access.
