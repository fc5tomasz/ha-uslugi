Project · Cameras and alarm

Cameras and alarm

One panel combines four camera views, alarm modes for selected areas or the entire home, sensor status and an event log. Each mode changes which areas are protected. Entering a protected area starts the disarm countdown and then triggers the alarm. Select “Simulate an intrusion” to see how the system responds to an intruder. This is a demonstration: the buttons work, but the panel is not connected to Home Assistant.
